# Security policy

Tovertoon is a static website with no accounts, no server code and no data collection. The realistic issues are in the build tooling and in third-party dependencies.

## Reporting a vulnerability

Please report privately through GitHub: **Security tab, "Report a vulnerability"**. Do not open a public issue for security problems. You will get a reply within a few days.

## Scope

- The deployed site and the code in this repository.
- Dependencies are tracked with Dependabot and scanned with CodeQL.
